# 录音记录功能测试用例

## 测试范围

- 新功能：录音结束自动保存、录音记录查询、播放、重命名、归档、筛选、继续转写。
- 配置：录音存储目录、自动归档、归档失败保护。
- 回归：浏览器录音、上传音频、转化记录、媒体清理、首页入口。
- UI：390px、768px、1440px 视口下的布局、文本溢出和操作可达性。

## 核心功能用例

| 编号  | 场景             | 前置条件                   | 操作                              | 预期结果                                                 |
| ----- | ---------------- | -------------------------- | --------------------------------- | -------------------------------------------------------- |
| RA-01 | 录音结束自动保存 | 麦克风可用                 | 完成一段不少于 3 秒的录音         | 完整性检查通过后出现“已保存到录音记录”，列表可找到该录音 |
| RA-02 | 稍后处理         | 已完成 RA-01               | 离开录音页并进入录音记录          | 未转写录音仍存在，状态为“未处理”                         |
| RA-03 | 上传音频进入记录 | 有合法音频文件             | 从“上传录音”提交文件              | 文件进入录音记录，同时原转写流程可继续                   |
| RA-04 | 筛选与搜索       | 至少有两条不同状态记录     | 按标题搜索并组合处理/保存状态筛选 | 只显示满足全部条件的记录                                 |
| RA-05 | 播放与下载       | 记录的应用内副本存在       | 播放并下载录音                    | 播放器可播放，下载文件名与原文件一致                     |
| RA-06 | 手工归档         | 配置了可写绝对路径         | 点击“归档到本地目录”              | 文件复制到目标目录，记录显示“已归档”且保留应用内副本     |
| RA-07 | 归档失败保护     | 配置路径不可写或源文件缺失 | 发起归档                          | 状态显示“归档失败”，错误可见，应用内记录不删除           |
| RA-08 | 自动归档         | 开启自动归档               | 完成录音或上传音频                | 创建记录后自动尝试归档，成功或失败状态可追踪             |
| RA-09 | 重命名           | 存在录音记录               | 修改标题并保存                    | 列表和详情同步展示新标题，源文件不变                     |
| RA-10 | 继续转写         | 存在未处理录音             | 点击“转写并生成笔记”              | 复用原媒体创建任务，跳转转化记录，源录音仍保留           |
| RA-11 | 用户隔离         | 两个不同账号有记录         | 分别读取相同接口                  | 每个账号只能看到自己的记录                               |
| RA-12 | 空状态           | 当前账号无记录             | 进入录音记录                      | 展示明确空状态和“开始录音”入口，无异常报错               |

## 回归与 UI 用例

| 编号  | 检查项                     | 预期结果                                     |
| ----- | -------------------------- | -------------------------------------------- |
| RG-01 | 首页“录音记录”入口         | 可进入真实记录页，路由与返回入口均正常       |
| RG-02 | 浏览器录音暂停、恢复、试听 | 原流程不受影响，录音资产保存不会阻断试听     |
| RG-03 | 音频上传转写               | 原任务创建、进度和失败提示不受影响           |
| RG-04 | 转化记录                   | 通过录音记录创建的任务可按 jobId 打开        |
| RG-05 | 媒体清理                   | 原“媒体清理”设置项保留，录音存储为独立配置项 |
| UI-01 | 390px                      | 页面无横向溢出，筛选控件换行，主操作可见     |
| UI-02 | 768px                      | 列表与详情按可用宽度排布，无文字遮挡         |
| UI-03 | 1440px                     | 列表与详情双栏，详情吸顶不覆盖页头           |
| UI-04 | 加载、空、失败状态         | 状态文案清楚，不出现空白页面或不可恢复操作   |
