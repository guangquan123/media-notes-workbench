## 已覆盖风险

- Windows 非法文件名字符和上海时区归档命名。
- 未处理、待归档、失败记录的排序与筛选。
- 录音清单跨服务实例持久化。
- 归档成功复制文件且不删除应用内源文件。
- 归档失败保留记录并展示失败状态。
- 账号之间的录音记录隔离。
- 录音页、上传音频页、录音记录页和设置页的接口契约。

## UI / 体验检查

- 使用现有平台路由和布局风格，入口位于首页“录音记录”和录音页头部。
- 列表、详情、播放器、筛选、归档设置和重命名均有明确状态和空态。
- 使用响应式双栏布局，窄屏下自动换行；标题、文件名和归档路径使用截断或换行保护。
- 浏览器自动化工具对本机 localhost 的部分深层 DOM 操作受策略限制，因此补充使用实际开发服务 HTTP、页面加载状态、生产构建和代码级响应式检查；未声称完成无法观察到的像素级断言。

## 已知边界

- 本版本的录音资产清单使用本地 JSON 文件，适合当前本地运行模式；多实例平台部署前应迁移到正式数据库表。
- 本版本的电脑本地归档仅在服务进程所在机器可访问的路径执行，平台远程运行时不能直接写用户个人电脑磁盘。
