# 静默环境准备与安装依赖方案

## 目标

- 首次引导不再展示“环境检查”步骤，用户只看到与配置能力相关的步骤。
- 安装包必须携带并安装 `ffmpeg.exe`、`ffprobe.exe`、`yt-dlp.exe` 及其运行所需 DLL。
- 安装完成后立即校验这些文件；缺失时安装器中止并提示重新安装，避免进入缺少依赖的半可用状态。

## 边界

- Whisper CLI 和模型权重继续不放入安装包。当前发布清单声明 `modelPolicy=external-only`，模型体积、授权和升级策略都不适合随安装器分发；转录优先使用腾讯 ASR 或兼容 API。
- 环境检查接口和能力门禁继续保留，作为后台能力状态和任务前校验使用，不再作为首次引导页面。
- 本机存储不可用仍然是硬错误，但会在引导当前页面提示，而不会跳转到独立环境检查页。

## 影响与实施

1. 引导状态机保留 `environment` 兼容值，但正常路径在欢迎页提交时后台调用环境校验，成功后直接进入 AI 服务配置；旧状态恢复时也自动绕过环境步骤。
2. 安装打包脚本将三个媒体工具列为硬依赖，源目录或发布目录缺任何一个都直接失败；安装清单固定记录这三个文件。
3. Inno Setup 增加安装后文件校验，验证工具和关键 FFmpeg DLL 存在；校验失败时阻止完成安装并给出日志位置。
4. 发布预检继续验证工具 SHA-256，确保“附带的依赖”不是空文件或被替换的版本。

## 验收

- 首次配置页面不出现环境检查步骤或进度条。
- 正常安装后 `tools` 目录包含三个可执行文件和 FFmpeg DLL。
- 删除任一工具后重新安装/修复时，安装器不会报告成功安装。
- 无 Whisper CLI/模型时，用户仍可通过已配置的外部转录服务使用音视频功能。
