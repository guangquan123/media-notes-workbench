# 提示词模板：多版本对比高保真原型

## 设计目标

让用户在当前提示词类型内，任意选择两个已保存版本，快速理解新增、删除和修改内容，并可回到原编辑上下文继续工作。

## 原型画板

打开 [prompt-version-compare.svg](D:/data/codex_space/media-notes-workbench/prototypes/prompt-version-compare.svg) 查看三种关键状态：

1. **入口态**：在当前生效版本旁增加“历史版本 3”和“对比版本”两个操作。
2. **版本选择态**：A/B 两个选择器、版本列表、对比方式和“查看差异”集中在一个工作区内完成。
3. **差异对比态**：双栏同步阅读，使用绿色/红色/橙色分别表达新增/删除/修改，并提供差异统计和筛选。

完整用户旅程请打开 [prompt-template-full-flow.html](D:/data/codex_space/media-notes-workbench/prototypes/prompt-template-full-flow.html)，可从“提示词配置”入口开始，依次体验选择模板、编辑、保存草稿、发布、历史版本和独立差异对比。

根据交互复审后的 UX v2 请打开 [prompt-template-ux-v2.html](D:/data/codex_space/media-notes-workbench/prototypes/prompt-template-ux-v2.html)。该版本将“选择模板 → 编辑 → 发布”保留为主任务，将“历史版本 → 版本比较”拆为当前提示词页面上的独立侧栏操作，比较完成后可直接返回当前提示词。

## 关键交互

- “对比版本”默认带入当前提示词类型，不跨类型混选。
- A、B 选择器均可选择 V1/V2/V3；两个选择相同版本时禁用“查看差异”并提示“请选择两个不同版本”。
- 默认排序为旧版本在左、新版本在右；允许交换 A/B，交换后颜色和标题随列同步变化。
- “并排对比”用于逐段阅读；“统一视图”用于按文档顺序浏览变更。
- 差异筛选支持“全部差异 / 新增 / 删除 / 修改”，统计数字与筛选结果保持一致。
- 点击差异条目时，两栏滚动到对应段落；返回时保留已选择的两个版本和筛选条件。

## 状态与边界

- 只有一个版本时，历史版本入口显示数量 1，“对比版本”置灰并说明“至少需要 2 个版本”。
- 草稿可参与对比，但必须在版本标签上明确“草稿”，避免误认为已生效内容。
- 大文本采用虚拟滚动或分段加载；差异摘要优先显示，避免一次渲染整篇提示词造成卡顿。
- 空差异时显示“两个版本内容一致”，不展示空白双栏。

## 视觉规范

- 沿用现有设置页的黑色活动导航、白色内容面板、蓝色主按钮和浅灰背景。
- 差异颜色仅作为辅助：新增 `#ECFDF3 / #027A48`，删除 `#FFF1F2 / #BE123C`，修改 `#FFF7ED / #C2410C`，同时保留文字标签，满足可访问性。
- 版本元信息统一显示：版本号、状态、更新时间、操作者、字符数。

## 本轮不包含

- 没有实现代码、数据结构、接口或发布逻辑。
- 没有定义差异算法；原型只验证信息层级和交互路径。
